# 🔧 INC – Návrh číslicových systémov

Projekt zameraný na návrh a simuláciu logických obvodov.

## 📌 Projekt

- [x] UART RX – návrh a implementácia riadiacej logiky prijímača
- [x] FSM, registre, čítače v jazyku VHDL
- [x] Simulácia správania obvodov (GHDL, GTKWave)

## 🛠️ Použité technológie

- VHDL
- GHDL, GTKWave
- RTL návrh, stavové automaty, kombinačná a sekvenčná logika
